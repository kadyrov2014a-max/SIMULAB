
# СИМУЛЯТОР — основы компьютерного моделирования

Интерактивный образовательный сайт на русском языке, который знакомит начинающих пользователей с основами компьютерного моделирования.

**Автор:** Амангельдиева Амина

## О проекте

Проект создан для изучения компьютерного моделирования в формате короткого интерактивного мини-урока.

Вместо одного лишь чтения теории пользователь может самостоятельно изменить параметры физической модели, запустить эксперимент, проанализировать результаты и пройти тест.

## Возможности

- Краткая теория компьютерного моделирования.
- Пошаговый план обучения.
- Интерактивная модель движения мяча.
- Настройка начальной скорости, угла броска и ускорения свободного падения.
- Автоматический расчёт дальности, максимальной высоты и времени полёта.
- Анимация движения и визуализация траектории.
- Объяснение результатов эксперимента.
- Пять вопросов с автоматической проверкой.
- Итоговый результат и индикатор прогресса.
- Адаптивный интерфейс для смартфонов, планшетов и компьютеров.
- Возможность пройти урок заново.

## Как запустить проект

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в современном браузере.
3. Изучите теорию и перейдите в виртуальную лабораторию.
4. Измените параметры движения и запустите эксперимент.
5. Пройдите тест и посмотрите результат.

Для публикации сайта можно использовать GitHub Pages.

## Публикация через GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в Settings.
3. Откройте раздел Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/(root)`.
6. Нажмите Save.
7. Дождитесь публикации сайта и откройте ссылку, которую покажет GitHub Pages.

## Научная модель

В симуляторе используется упрощённая модель движения тела, брошенного под углом к горизонту.

Сопротивление воздуха не учитывается. Предполагается, что тело начинает и заканчивает движение на одной высоте.

Формулы:

- Время полёта: `t = 2v sin(θ) / g`
- Дальность: `R = v² sin(2θ) / g`
- Максимальная высота: `H = v² sin²(θ) / (2g)`

Здесь:

- `v` — начальная скорость;
- `θ` — угол броска;
- `g` — ускорение свободного падения.

Это учебная модель, а не точный прогноз реального движения мяча с учётом всех физических факторов.
